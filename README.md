# 🏠 My Home Planner

Mobile-friendly apartment and moving planner using plain HTML, CSS and JavaScript.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, and `manifest.json`.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and wait for GitHub Pages.

## Data
Your data is stored in your browser's local storage. Use **Export** regularly to create a JSON backup. Use **Import** to restore it on another device.

## Budget
Initial housing targets are 30%, 35%, and 40% of take-home pay after subtracting entered monthly bills. These are planning targets, not financial advice.
